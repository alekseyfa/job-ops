## Known Limitations

**ZipRecruiter API Availability**: The extractor implementation is a structural scaffold. ZipRecruiter's public API typically requires authentication. The current `run.ts` returns an empty job array with a note about API unavailability. This is intentional — the extractor structure is validated, but live job fetching may require:
- API key (if ZipRecruiter offers a partner API)
- RSS feed parsing (ZipRecruiter publishes job RSS feeds)
- Web scraping fallback (last resort, fragile)

The Docker build and type-check validation confirm the extractor is correctly registered and integrated. Live job fetching is deferred to production deployment when API access is secured.
